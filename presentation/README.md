# 매장수첩 — 단일 파일 버전

발표·시연용. **서버 없이 파일 하나로 동작한다.**

| 파일 | 용도 |
|---|---|
| `매장수첩.html` | **이걸 쓰면 된다.** 더블클릭하면 브라우저에서 열린다 |
| `app.html` | 위 파일의 알맹이. Artifact 게시용 (doctype 없음) |

## 왜 만들었나

`npm run dev`로 띄우는 원본은 서버가 살아 있어야 한다. 발표장에서
인터넷이나 개발환경이 없을 수 있고, 노트북이 바뀔 수도 있다.
이 파일은 USB에 넣어 가도 되고 메일로 보내도 열린다.

**2026-09-07 — 외부 요청이 0건이 됐다.** 그전에는 글꼴을 Google Fonts에서
받아서, 정작 "인터넷 없이 열린다"는 이 파일의 존재 이유와 어긋나 있었다.
`<link>` 3줄을 지우고 기기에 이미 깔린 글꼴만 쓰도록 바꿨다.
**이제 랜선을 뽑아도 처음 열 때와 똑같이 뜬다.** → `docs/deliverables/06_보안설계.md` V-12

## 원본과 다른 점

- 데이터가 파일 안에 박혀 있다 (`data/seed.json`을 복사해 넣은 것)
- 화면 전환은 주소 뒤 `#/prep/afternoon` 같은 해시로 한다
- 저장은 localStorage. 파일로 열면 막히는 브라우저가 있어 메모리로 물러난다
  (새로고침하면 초기화된다 — 시연에는 문제없다)

**원본을 고치면 이 파일도 같이 고쳐야 한다.** 자동으로 따라가지 않는다.
