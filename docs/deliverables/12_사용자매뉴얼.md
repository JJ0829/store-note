**하실 일**

1. **[제빵 순서 보기]** 를 누르세요. **교육 모드**가 열립니다. 가운데 **[시작하기]** 를 누르면 제빵 8개 항목이 **한 장씩** 큰 글씨로 넘어갑니다.

   - **[어제 것 받기]** — 르방 상태 확인 / 냉장 발효 반죽 꺼내 실온 복원

3. 세 번째 덩어리에는 **[오늘은 아무 일도 안 생깁니다. 안 하면 내일 아침에 터집니다]** 라는 설명이 딸려 있습니다.
   > **화면에서 찾지 마세요.** 이 설명은 체크리스트(`/p/bakery-morning`) 화면에서 섹션 제목 옆에 붙습니다. 교육 모드에는 섹션 이름만 화면 맨 위에 뜹니다.
4. 배합량을 다시 볼 때는 **[레시피 찾기]** → **[식빵 (1배합)]**.

> **알아두실 것.** 이 버튼은 **교육 모드**로 연결됩니다. 매일 스크롤하며 체크하는 형태로 보고 싶으면, 첫 화면을 아래로 내려 **[포지션별 체크리스트]** 의 **[체크리스트]** 를 누르세요. 그쪽은 체크가 저장됩니다.

| 이스트 | 40g | 60g |

**레시피 화면에서 하는 방법**

첫 화면 → **[레시피 찾기]** → **[식빵]** → 맨 위 **[1.5배]**.

> 두 화면의 계산은 같은 방식입니다. 숫자가 다르게 나올 일은 없습니다.

## 3-2. "직원이 새로 들어왔다"

**첫날 — 태블릿 앞에 앉히세요**

1. 첫 화면 → **[포지션별 체크리스트]** 에서 해당 포지션의 주황색 **[교육 모드로 열기]**
2. **[시작하기]** 를 누르게 하고, 옆에서 시연하며 한 장씩 넘깁니다.
3. 빨간 **[꼭 지키기]** 항목에서는 **[읽었습니다]** 를 누르기 전에는 안 넘어갑니다. 그때 실제로 보여주세요.
4. 끝나면 **[보는 동안 선배에게 몇 번 물어보셨나요?]** 에 답하게 합니다.

**둘째 날부터 — 링크를 보내주세요**

1. 같은 자리에서 **[링크 복사]** 를 누릅니다. 잠깐 **[복사됨]** 으로 바뀝니다.
2. 카톡으로 신입에게 보냅니다.
3. 신입은 자기 폰에서 그 링크를 열고 체크하면서 일합니다.

> 복사가 안 되고 **[아래 주소를 복사해서 카카오톡에 붙여넣으세요]** 팝업이 뜨면 정상입니다. 팝업 안의 주소를 그대로 복사하세요.
> **신입이 뭘 체크했는지는 사장님 화면에 안 나옵니다.** 확인하려면 직접 물어보셔야 합니다.

**첫 촬영을 신입에게 시키세요**

선배가 시연하고 신입이 폰으로 찍습니다. 어차피 시연은 하니까 추가로 드는 시간이 없고, 다음 신입이 그 영상을 봅니다. 넣는 방법은 3-5.

## 3-3. "다음 주 근무표를 짜야 한다"

1. 첫 화면 → **[이번 주 근무표]**
2. 처음이라면 **[직원 추가]** 부터. 섹션 버튼(**[제빵] [바] [홀] [주방]**)을 누르고 이름·이메일·전화번호를 넣고 **[추가]**.
   → 한 번 넣으면 다음부터는 안 넣어도 됩니다.
3. 날짜 줄 오른쪽의 **[다음주 ›]** 를 눌러 다음 주로 이동합니다.
4. 직원 × 요일 칸마다 **[휴무] [제빵 05:00] [오픈조 07:30] [미들 11:00] [마감조 14:30]** 중에 고릅니다. 고를 때마다 자동 저장됩니다.
5. **[메일로 보내기 (N명)]** 을 누릅니다. → 메일 앱이 제목과 본문까지 채워진 채로 열립니다.
6. **내용을 눈으로 확인하고 직접 [보내기] 를 누르세요.**

메일 본문은 이렇게 나갑니다.

```
○○ 베이커리 카페 근무표
9/7(월) ~ 9/13(일)

[ 직원 명단 ]
섹션    이름      이메일                   전화번호
----------------------------------------------------------------
바      김민수    kim@example.com          010-0000-0000

[ 이번 주 근무 ]

● 바
  - 김민수
    9/7(월) 오픈조  /  9/8(화) 오픈조  /  9/9(수) 휴무  ...

변경 사항이 있으면 알려주세요.
```

> 카톡으로 돌리려면 **[복사 (카톡용)]** 를 누르세요. 되면 **[근무표를 복사했습니다. 단톡방에 붙여넣으세요.]** 라고 뜹니다.
> **⚠ 매장 태블릿에서는 눌러도 아무 일이 안 일어날 수 있습니다.** 매장 접속 주소는 보안 연결이 아니라 복사가 막히는데, 막혔다는 표시도 안 뜹니다. 그때는 **앱이 도는 컴퓨터에서 (`http://localhost:3000/roster`) 누르시거나**, **[메일로 보내기]** 를 쓰세요.

## 3-4. "새 메뉴를 넣고 싶다"

1. 첫 화면 → **[레시피 찾기]** → 주황색 **[+ 레시피 추가]**
2. **[메뉴 이름]** 을 넣습니다. 별표가 붙은 필수 항목입니다.
3. **[분류]** 를 고릅니다. **[음료] [베이커리] [브런치] [기타]**

5. **[재료]** 를 채웁니다. 이름 · 양 · 단위 · 메모. 줄이 모자라면 **[+ 재료 추가]**.

8. 아래 고정된 주황색 **[저장]**.

저장이 안 눌리면 아래에 **[메뉴 이름과 재료 한 줄은 있어야 저장됩니다.]** 가 떠 있습니다.

> **꼭 아셔야 할 것**
> 추가한 레시피는 **그 태블릿에만** 저장됩니다. 목록에서 **[직접 추가]** 표로 구분됩니다.
> **한 번 저장하면 고칠 수 없습니다.** 지우고 다시 넣는 방법뿐입니다(레시피 화면 맨 아래 **[이 레시피 삭제]**).
> 여러 개를 넣었다면 레시피 목록 아래 **[백업용으로 복사하기]** 를 눌러 어딘가에 붙여넣어 보관하세요. 태블릿을 초기화하면 전부 사라집니다.
> **다만 이 버튼은 매장 태블릿에서 눌러도 아무 일이 안 일어날 수 있습니다.** (아래 5장 참고) 백업은 **앱이 도는 컴퓨터에서 (`http://localhost:3000/r`) 하세요.**

## 3-5. "사진을 넣고 싶다"

**파일 이름이 전부입니다.** 이름만 맞으면 화면에 자동으로 붙습니다.

1. 첫 화면 → **[촬영 진행 보기]**
2. **[먼저 찍을 것]** 4개부터 찾습니다.

| 무엇을 | 넣을 파일 이름 |
|---|---|
| 추출 테스트 — 합격 / 불합격 | `t-open-5-good.jpg` / `t-open-5-bad.jpg` / `t-open-5.mp4` |
| 스팀 밀크 — 고운 거품 / 거친 거품 | `s-lt-2-good.jpg` / `s-lt-2-bad.jpg` / `s-lt-2.mp4` |
| 르방·발효 — 완료 / 과발효 | `t-bake-1-good.jpg` / `t-bake-1-bad.jpg` / `t-bake-1.mp4` |
| 콜드브루 거는 장면 | `p-1-good.jpg` / `p-1-bad.jpg` / `p-1.mp4` |

3. 폰으로 찍습니다. **영상은 30초, 편집하지 마세요.**
4. 화면에서 **[좋은 예]** 칸을 눌러 파일명을 복사하고, 그 이름으로 저장합니다.
5. 파일을 **`public/media/` 폴더**에 넣습니다.
6. 촬영 화면을 새로고침하면 회색 ＋ 가 초록 ✓ 로 바뀝니다.

**이름 규칙 (전체 57개 공통)**

```
앞부분-good.jpg   ← 좋은 예 (사진)
앞부분-bad.jpg    ← 나쁜 예 (사진)
앞부분.mp4        ← 영상
```

- 사진은 `.jpg` `.jpeg` `.png` `.webp` 다 됩니다.
- 영상은 `.mp4` `.mov` `.webm` 다 됩니다.
- **좋은 예 하나만 있어도 화면에 붙습니다.** 나쁜 예는 없으면 그냥 안 보입니다.
- "앞부분"이 무엇인지는 촬영 화면에서 항목 이름 아래 회색 글씨로 나와 있습니다. `public/media/촬영목록.md` 에도 전체 표가 있습니다.

들어가면 이렇게 붙습니다. 사진 두 장이면 나란히, 아래에 초록 **[이렇게]** / 빨강 **[이러면 안 됨]** 이라고 적힙니다. 영상이 있으면 그 아래에 재생 막대가 붙습니다.

> **올리기 버튼은 없습니다.** 파일을 폴더에 직접 넣어야 합니다. 태블릿에서는 못 하고, 앱이 돌아가는 컴퓨터에서 해야 합니다.

# 4장. 아직 안 되는 것

**기대하고 계셨다면 여기서 확인하세요.** 아래는 전부 지금 **안 되는 것**입니다.

## 알림이 없습니다

- **"14:00에 콜드브루 거세요"라고 알려주지 않습니다.** 사람이 화면을 열어야 보입니다.
- 프렙을 안 했다고 사장님께 연락이 가지도 않습니다.

## 여러 기기에서 같이 못 봅니다

**이게 제일 자주 오해하는 부분입니다.**

- 태블릿에서 추가한 레시피는 **다른 태블릿에서 안 보입니다.**
- 신입이 폰에서 체크한 것은 **사장님 화면에 안 뜹니다.**

같이 보려면 서버 연결이 필요한데, 아직 없습니다. 화면에도 **[여러 기기에서 함께 쓰려면 서버 연결(배포 직전 작업)이 필요합니다.]** 라고 적혀 있습니다.

- 회원가입이 없습니다. 계정도 없습니다. 그래서 **누가 무엇을 했는지 기록되지 않습니다.**
- 레시피 화면에도 **잠금이 없습니다.** 검색에는 안 걸리게 막아뒀지만, **주소를 아는 사람은 그냥 들어옵니다.** 매장 PIN은 예정만 있고 아직 없습니다.
- 그러니 **레시피 주소는 카톡·SNS에 올리지 마세요.**

## 복사 버튼 세 개가 매장 태블릿에서 안 됩니다

매장 접속 주소(`http://…:3000`)는 **보안 연결이 아니라** 브라우저가 복사 기능을 막습니다.

- **촬영 화면의 파일명 칸** · **레시피 [백업용으로 복사하기]** · **근무표 [복사 (카톡용)]** — **이 셋에는 대신 뜨는 팝업이 없습니다.** 눌러도 **아무 일도 안 일어납니다.** 실패했다는 표시조차 안 뜹니다.
- **앱이 도는 컴퓨터에서 (`http://localhost:3000`) 누르면 정상 동작합니다.** 이게 지금 유일한 방법입니다.

## 사진 올리기 버튼이 없습니다

- 앱 안에서 사진·영상을 올릴 수 없습니다. **파일을 손으로 폴더에 넣어야 합니다.** (3-5 참고)
- 태블릿만으로는 못 합니다.

# 5장. 데이터가 사라지는 경우

**"내가 적은 게 언제까지 남는가"** 를 정확히 적었습니다. 저장되는 곳은 서버가 아니라 **그 기기의 브라우저**입니다.

| 무엇 | 어디에 남나 | 언제까지 |
|---|---|---|
| 체크리스트 체크 (`/p/...`) | 그 기기 | **날짜가 바뀌면 화면이 비워집니다** |
| 프렙 체크 (`/prep/...`) | 그 기기 | **날짜가 바뀌면 화면이 비워집니다** |
| 교육 모드 진행 | 그 기기, 그 탭 | **브라우저 탭을 닫으면 사라집니다.** [끝내기]를 눌러도 사라집니다 |
| 직접 추가한 레시피 | 그 기기 | **지우기 전까지 계속 남습니다** |
| 직원 명단 · 근무표 | 그 기기 | **지우기 전까지 계속 남습니다** |
| 배수(몇 배) 선택 | 아무 데도 안 남습니다 | 화면을 나가면 사라집니다 |
| 사용 기록(열람·완료·설문) | 앱이 도는 컴퓨터의 파일 | 계속 쌓입니다. 화면으로 볼 수는 없습니다 |

## 반드시 알아두실 것

**1. "날짜가 바뀌면 초기화"의 정확한 뜻**

자정이 지나면 앱이 **새 칸에 쓰기 시작합니다.** 그래서 화면은 깨끗해집니다. 다만 어제 체크한 내용이 브라우저 안에서 즉시 지워지는 것은 아닙니다. 화면에 다시 나타나지 않을 뿐입니다.

**2. 이럴 때 전부 사라집니다**

- 브라우저 **인터넷 사용 기록 삭제 / 사이트 데이터 삭제**
- 태블릿 **초기화**
- **시크릿 모드(사생활 보호 모드)** 로 연 경우 — 창을 닫으면 사라집니다

**3. 그래서 이건 꼭 하세요**

- **직접 추가한 레시피가 쌓였다면** 레시피 목록 아래 **[백업용으로 복사하기]** 를 눌러, 메모장이나 메일에 붙여넣어 보관하세요.

  > 태블릿에서는 **[복사 (카톡용)]** 이 무반응일 수 있으므로 **[메일로 보내기]** 쪽이 안전합니다.

직원 이름·이메일·전화번호가 그 태블릿에 남아 있습니다. **브라우저 설정 → 인터넷 사용 기록 삭제(사이트 데이터 포함)** 를 실행하세요. 앱 안에는 "전부 지우기" 버튼이 없습니다.

# 7장. 두 가지 버전 — 어느 것을 언제 쓰나

같은 내용이 **두 가지 모습**으로 있습니다.

- **웹앱** — 앱이 도는 컴퓨터에서 서버를 켜두고, 태블릿 브라우저에 **`http://<앱이 도는 컴퓨터 IP>:3000`** 을 칩니다. IP 확인과 서버 켜는 법은 **`11_설치가이드.md`**.
- **파일 하나** — 프로젝트 폴더의 **`presentation/프렙노트.html`** 파일입니다. 이 파일 하나만 USB나 메일로 옮겨서 더블클릭하면 열립니다. 서버도 인터넷도 필요 없습니다.

| | **웹앱** (원본) | **파일 하나** (`프렙노트.html`) |
|---|---|---|
| 여는 법 | 태블릿 브라우저에 **`http://<컴퓨터 IP>:3000`** 입력 | 파일 **`presentation/프렙노트.html`** 을 **더블클릭** |
| 준비물 | 컴퓨터 한 대가 켜져 있어야 함 | 없음. USB·메일로 옮겨도 열림 |
| 화면 이동 | 뒤로 버튼과 링크만 | **아래에 탭바 5개** — 오늘 / 프렙 / 레시피 / 근무표 / 교육 |
| 주소 모양 | `/prep/afternoon` | `#/prep/afternoon` |
| 촬영 진행 화면 | **있음** | **없음** |
| 사진·영상 | 넣으면 화면에 붙음 | **회색 칸에 [좋은 예 / 촬영 후 여기] 로 고정** |
| 레시피 추가 | 있음 (`/r/new` 화면) | 있음 (목록 안에서 바로 입력) |
| 근무표 메일 | 됨 | 됨 |
| 사용 기록 쌓기 | 됨 | **안 됨** |
| 저장 | 그 기기에 남음 | **파일로 열면 새로고침 시 초기화될 수 있음** |
| 글꼴 | 태블릿 기본 글꼴 | 인터넷이 없으면 모양이 달라짐(내용은 같음) |

**이렇게 쓰세요.**

- **발표·시연** → 파일 하나. 노트북이 바뀌어도, 인터넷이 없어도 열립니다. **다만 발표 전에 반드시 한 번 인터넷 없이 열어보세요.**
- **매장에서 실제로 쓰기** → 웹앱. 사진이 붙고 기록이 쌓이는 쪽은 이쪽뿐입니다.
- 두 버전은 **자동으로 같아지지 않습니다.** 한쪽 내용을 고치면 다른 쪽도 따로 고쳐야 합니다.

# 8장. 이 앱에서 쓰는 말

화면에 나오는 단어를 **이 앱에서 어떤 뜻으로 쓰는지** 적었습니다.

**프렙**
영업 전에 미리 해두는 준비 작업. 이 앱에서는 특히 **오늘 해야 내일 쓸 수 있는 것**을 가리킵니다. 첫 화면 설명도 **[오늘 해야 내일 쓸 수 있는 것들입니다.]** 입니다.

**리드타임**
걸어두고 나서 **실제로 쓸 수 있을 때까지 걸리는 시간.** 화면에는 시간 대신 **[지금 걸면 → 내일 06:00부터 사용 가능 (16시간)]** 처럼 **완성 시각으로** 나옵니다. 발주 항목은 **[오늘 주문 → 9/7(월) 도착 (주말 배송 없음)]** 처럼 **도착 날짜로** 나옵니다. 토·일은 배송일로 세지 않기 때문에 **토요일·일요일 날짜는 절대 나오지 않습니다.**

**되돌릴 수 없는 것 / [까먹지 말 것]**
오늘 빠뜨리면 **내일 아침에 어떤 방법으로도 못 메우는 것.** 화면에서 **빨간 테두리**가 쳐집니다.
오후 프렙에서는 **콜드브루 · 반죽 · 르방 · 원두 발주 넷이 빨간 테두리**입니다. 발주라도 **거래처 원두는 다른 데서 못 사기 때문에** 여기 들어갑니다.
**회색은 시럽 제조와 우유·식자재 발주 둘**입니다. 시럽은 남은 걸로 버틸 수 있고, 우유·식자재는 급하면 다른 데서 살 수 있습니다.
**전부 빨갛게 하면 아무도 안 봅니다. 그래서 골라서 표시합니다.**

**[꼭 지키기]**
위생·안전 항목. 빨간 작은 표로 붙습니다. 교육 모드에서는 이 항목마다 **[읽었습니다]** 를 눌러야 다음으로 넘어갑니다.

**배수 / 1배합**
**1배합**은 그 레시피를 한 번 돌렸을 때 나오는 양입니다. 식빵은 1배합에 6개. **배수**는 거기에 곱하는 숫자입니다. 9개가 필요하면 **1.5배**.

**배합률 (%)**
밀가루를 100으로 놓고 나머지 재료를 비율로 적은 것. 식빵의 물 60%, 소금 2%가 그것입니다. **배수를 곱해도 퍼센트는 그대로입니다.** 그래서 기준이 됩니다.

**르방**
직접 기르는 발효종. 매일 같은 시간에 갱신해야 합니다. **한 번 거르면 되살리는 데 2~3일 걸리고, 그동안 사워도우 전 품목이 멈춥니다.** 그래서 되돌릴 수 없는 것에 들어가 있습니다.

**포지션**
자리·역할. 이 앱에는 오픈조 · 마감조 · 제빵 세 가지가 있습니다.

**조 (근무조)**
그날 그 시간에 나오는 사람 묶음. 제빵 05:00 / 오픈조 07:30 / 미들 11:00 / 마감조 14:30. **첫 화면에 어떤 버튼을 띄울지가 이걸로 정해집니다.**

**섹션**
근무표에서 직원을 묶는 단위. 제빵 · 바 · 홀 · 주방. 직접 쳐 넣어도 됩니다.

**교육 모드**
매장 태블릿에서 **한 번에 한 항목씩** 큰 글씨로 넘겨 보는 화면. 첫날 교육용입니다.

**체크리스트 링크**
신입 폰으로 보내는 주소(`/p/...`). **비밀번호가 없는 공개 주소**입니다. 새어 나가도 큰 문제는 없지만, **레시피 주소는 절대 이렇게 돌리지 마세요.**
