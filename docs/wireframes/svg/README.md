# Figma 에 넣는 SVG

작성 2026-09-11 · 매장수첩

Figma 파일 **「매장수첩 — 화면설계서」**(`figma.com/design/hcBwohbWIFP3Bb0o093ndx`)에
**끌어다 놓아서** 넣는 화면들이다.

---

## 왜 SVG 인가

Figma MCP 가 **Starter 요금제 호출 한도**에 걸려 있다. 읽기도 쓰기도 안 된다
(2026-09-11 재확인 · [21_화면명세.md §8-3](../../deliverables/21_화면명세.md)).
한도는 **결제 주기 기준 월 1회** 리셋이라 발표(9/18) 전에 풀린다는 보장이 없다.

**SVG 는 그 한도를 아예 안 쓴다.** 캔버스에 떨어뜨리면 Figma 가 알아서
프레임·도형·**진짜 텍스트 레이어**로 바꿔 준다. 들어간 뒤에는 Figma 안에서
그냥 고치면 된다 — 다시 나한테 안 와도 된다.

---

## 넣는 법

1. Figma 에서 **매장수첩 — 화면설계서** 를 연다
2. 탐색기에서 `.svg` 파일을 **캔버스 위로 끌어다 놓는다**
   (메뉴로 하려면 `파일 → 가져오기`)
3. 들어온 프레임을 **보드 안 빈자리로 옮긴다.** 보드는 3360 넓이에 화면 넷이 들어간다
4. 레이어 이름을 옆 화면들과 같은 꼴로 바꾼다 — 예: `S-11 발주`

### 들어간 직후 확인할 것 두 가지

| | 무엇 | 왜 |
|---|---|---|
| 1 | **글꼴이 깨졌는가** | SVG 는 `Noto Sans KR` 로 써 뒀다. 옆 화면들이 다른 글꼴이면 프레임을 통째로 고르고 한 번에 바꾼다 |
| 2 | **세로 길이가 1024 인가** | 옆 화면과 높이가 같아야 나란히 선다. 다르면 내가 치수를 잘못 잡은 것이니 알려주시라 |

---

## 만들 때 지키는 규칙

**치수는 788 × 1024.** 같은 파일 `S-09 출퇴근 · 근태` 그룹의 실측값이다.
내가 정한 숫자가 아니라 **이미 있는 화면에서 잰 값**이라, 어긋나면 잰 쪽이 기준이다.

**색은 코드의 Tailwind 값을 그대로 옮긴다.** 지어내지 않는다.

| 쓰임 | 값 |
|---|---|
| 강조 (버튼·켜진 칩·탭) | `orange-500` `#f97316` · 탭 글자 `orange-600` `#ea580c` |
| 되돌릴 수 없음 · 경고 | `red-300` `#fca5a5` · `red-600` `#dc2626` · 바탕 `red-50` `#fef2f2` |
| 글자 | `zinc-900` `#18181b` · 보조 `zinc-500` `#71717a` · 흐림 `zinc-400` `#a1a1aa` |
| 선 · 테두리 | `zinc-200` `#e4e4e7` · 입력칸 `zinc-300` `#d4d4d8` |
| 화면 바탕 | `zinc-50` `#fafafa` |

**내용은 코드와 시드에서 뽑는다.** 화면에 있지도 않은 말을 그려 넣으면
그 그림은 합의문이 아니라 상상도가 된다. 지어낸 값이 있으면 SVG 머리 주석에 적어 둔다.

---

## 한계 — 알고 쓰자

- **오토레이아웃은 안 따라간다.** 들어간 뒤 Figma 에서 붙여야 한다
- **컴포넌트·변수에 연결되지 않는다.** 디자인 토큰을 쓰려면 들어간 뒤 다시 묶어야 한다
- 그래서 이건 **"화면을 Figma 안으로 옮기는 수단"** 이지 디자인 시스템을 만드는 수단이 아니다
