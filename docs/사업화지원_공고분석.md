### p.8 — Ⅲ-1. 평가 절차 / Ⅲ-2. 산출식 / Ⅲ-3. 1차 평가 기준

```
최종점수(100) = 1차 데모데이 환산(30) + 2차 선정평가 환산(70)
· 1차 환산 = (외부 전문가 3인 평균 ÷ 100) × 30
· 2차 환산 = (선정심의위원 평균 ÷ 100) × 70
· 소수 셋째 자리 반올림
```

**1차 = 데모데이 (9/18) — 30%**

| | |
|---|---|
| 평가위원 | 외부 전문가 **3인** — 창업·사업화 1 / 기술(AI·SW) 1 / 투자·시장 1 |
| ★ 발표 방식 | **팀당 발표 5분 + 질의응답 3분**(참가 팀 수에 따라 조정) · **MVP 실연 또는 시연 영상 필수** |
| 채점 | 위원별 100점 독립 채점 → **3인 산술평균 (최고·최저 제외 없음)** |
